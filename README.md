# The Scaramucci Converter

Convert any span of time into Scaramuccis. 1 Scaramucci = 866,700 seconds, Anthony Scaramucci's tenure as White House Communications Director (Jul 21, 2017 2:00 PM EDT to Jul 31, 2017 2:45 PM EDT).

- `index.html`: the converter
- `zacharia/index.html`: a live counter for Katie Zacharia's time as press secretary, and when it reaches parity with 1 Scaramucci

Plain static HTML, no build step. Hosted with GitHub Pages from `main` / root.
